# 기획서 — 성경 음성 검색 (설교 중 말한 구절을 바로 다음 장에)

- 작성일: 2026-10-30
- 상태: **1~4단계 구현** — 5절의 추천안대로. macOS·Windows 실제 음성은 사람이 말해 보며 확인해야 한다(Windows 는 PR CI 컴파일만)

---

## 0. 한눈에 보기

| 항목 | 내용 |
|---|---|
| 목표 | 설교 중 "요한복음 3장 16절" 이라고 **말하면** 그 구절 페이지를 **현재 페이지 바로 다음 장**에 넣어 둔다. 운영자는 → 한 번이면 띄운다 |
| 켜는 곳 | **발표 보기 탭 툴바에만** '성경 음성' 버튼. 편집 탭에는 없다. 발표 보기를 벗어나면 저절로 꺼진다 |
| 켜기·끄기 | 버튼을 켜 두면 **계속 듣는다**, 끄면 바로 마이크를 끈다(사용자 확정 2026-10-30). 다시 켜도 기억하지 않는다 |
| 역본 | **기본 새번역**(없으면 첫 역본). "개역개정" 처럼 역본 이름을 말하면 그 뒤로는 그 역본으로 찾는다(역본만 말해도 바뀐다). 켤 때마다 새번역으로 돌아간다 |
| 인식 | **OS 내장 음성 인식** — macOS `SFSpeechRecognizer`(ko-KR), Windows `Windows.Media.SpeechRecognition`. 악보 OCR(`worship_slides/ocr`)과 같은 구조의 새 채널 `worship_slides/speech` |
| 알아듣는 말 | **장절만**(책 + 장 + 절, 범위). 본문 낭독으로 찾기는 2차(아래 6) |
| 넣는 방식 | 성경 검색 탭에서 절을 골라 담은 것과 **똑같은 항목**(`BibleStagingItem`, 보조·추가 역본·페이지 나누기 그대로). 자리는 발표 보기 붙여 넣기와 같은 `_insertItemsAfterSlide` |
| 관객 화면 | **바뀌지 않는다.** 넣기만 하고 운영자가 넘긴다(자동으로 띄우기는 결정 항목) |

## 1. 화면

```
발표 보기 툴바
[◀][▶] … [새 페이지 ▾] [🎤📖 성경 음성]  [🎤 싱어] [📱]
                          │
                          └ 켜면 툴바 아래 얇은 줄이 생긴다
┌──────────────────────────────────────────────────────────────────┐
│ ● 듣는 중   "요한복음 삼 장 십육 절…"(회색, 중간 결과)                     │
│ ✔ 다음 장에 넣음: 개역개정 요한복음 3:16  [바로 띄우기] [되돌리기]  ✕        │
└──────────────────────────────────────────────────────────────────┘
```

- 버튼: 기존 싱어 화면 마이크(`Icons.mic_rounded`)와 헷갈리지 않게 성경 아이콘 + 작은 마이크, 켜지면 강조색(테마 `primary`)
- 상태 줄
  - `● 듣는 중` + 지금 들리는 말(중간 결과, 회색, 한 줄 말줄임) — 마이크가 살아 있는지 운영자가 눈으로 안다
  - 넣으면 `✔ 다음 장에 넣음: <구절>` + **바로 띄우기**(= 다음 장으로 넘기기) · **되돌리기**(넣은 항목 빼기). 다음 인식이 오거나 30초 지나면 사라진다
  - 못 찾으면 `"요한복음 3장 99절" — 없는 절` 처럼 들은 말과 이유를 보여 준다(아무것도 안 넣는다)
- 썸네일 줄: 넣은 페이지에 잠깐(3초) 테두리 깜빡임 — 어디 들어갔는지 보인다
- 권한·설치 문제(마이크 거부, 한국어 음성 팩 없음)는 켤 때 안내창. LibreOffice·Tesseract 처럼 "그 기능만 막는다"

## 2. 동작

### 2-1. 켜기·끄기
- 발표 보기 탭에서만 버튼이 보인다. 탭을 편집으로 바꾸거나 발표를 끝내면 끈다(마이크 해제)
- 발표 창이 안 열려 있어도 발표 보기 탭이면 쓸 수 있다(리허설용)

### 2-2. 말 → 구절 (Dart 순수 함수, `bible_voice_parse.dart`)
인식 엔진이 주는 글(최종 결과)을 받아 구절을 뽑는다.

**기본 말하기 방식(사용자 확정 2026-10-30)** — 이렇게 말하면 바로 찾아 넣는다:

| 들은 말 | 결과 |
|---|---|
| `다니엘 3장 1절에서 10절` / `다니엘 3장1절에서 10절` | 다니엘 3:1-10 |
| `에베소서 1장 1절` | 에베소서 1:1 |
| `시편 107편 5절` | 시편 107:5 (시편은 `편` = 장) |

그 밖에 같이 알아듣는 변형:

| 들은 말 | 결과 |
|---|---|
| `요한복음 3장 16절` / `요한복음 삼 장 십육 절` | 요한복음 3:16 |
| `로마서 8장 28절부터 30절까지` / `28절에서 30절까지` / `28절 ~ 30절` | 로마서 8:28-30 |
| `시편 23편` | 시편 23장 전체 |
| `고린도전서 13장` / `고린도 전서 13장` | 13장 전체 |
| `요한일서 4장 8절` / `요한 1서` / `요일 4장 8절` | 요한일서 4:8 |
| (직전에 요한복음 3장) `17절` / `18절도` | 요한복음 3:17 — **같은 장 이어 말하기** |
| `오늘 말씀은 이사야 40장 31절 말씀입니다` | 이사야 40:31 (앞뒤 말은 무시) |

- 숫자: 아라비아 숫자 + 한자어 수사(`일·이·삼…십·백`, `이십삼`, `백오십`) 둘 다. 붙여 쓰기·띄어 쓰기 무시(`bibleIgnoredSpaces` 재사용)
- 책 이름: 지금 역본의 66권 이름(`getBookNames`) + 별칭표(`요일`, `고전`, `창`, `계` …, 띄어 쓴 `고린도 전서`, 인식기가 흔히 틀리는 `요한 복음`). 정경 순서 index 로 맞추므로 역본이 달라도 같다
- 장 전체(절 없음)는 **장 전체를 넣지 않고** 1절만? → 결정 항목 D. 기본안: 장 전체를 `bibleVersePages` 로 나눠 넣는다
- 한 문장에 구절이 둘이면(`3장 16절과 17절`) 범위로, 서로 다른 책이면 **마지막 것만**(설교자가 고쳐 말한 것으로 본다)

- 역본: DB 역본 이름(공백 무시, "개역 개정" = 개역개정) + 영문 약자 소리(`엔아이브이` = NIV). 한 마디에 여럿이면 마지막 것

### 2-3. 넣기
- 성경 패널(`_BiblePanel` 의 담기 코드, `praise_home_page.dart` 6560 근처)에서 페이지 만들기 + 보조·추가 역본 붙이기 부분을 **함수로 떼어** 패널과 음성 검색이 같이 쓴다. 성경 검색 탭에서 담은 것과 글자 하나 다르지 않다
- 역본 = 성경 검색 패널에서 지금 고른 역본, 페이지당 절 수 = 지금 `_versesPerPage`
- 자리 = 발표 보기 붙여 넣기와 같은 `_insertItemsAfterSlide`(현재 페이지 바로 뒤, 곡·PPT 중간이면 나눈다, 자동 여백 규칙 그대로)
- **중복 막기**: 바로 다음 장이 이미 같은 구절이면 넣지 않는다. 같은 구절을 10분 안에 또 들으면 넣지 않고 `이미 넣음 → [그 장으로]` 만 보여 준다(설교자는 같은 구절을 여러 번 말한다)
- 되돌리기 = 넣은 항목 uid 로 `_removeStagingWhere`(나눈 항목은 그대로 둔다 — 붙여 넣기 되돌리기가 없는 것과 같은 수준)
- 콘티 저장·PPTX 에는 평소 항목처럼 실린다(따로 표시하지 않음)

### 2-4. 인식 엔진 (네이티브 채널 `worship_slides/speech`)
- Dart → 네이티브: `isAvailable` / `start` / `stop`
- 네이티브 → Dart(`presentation_main` 처럼 콜백): `partial {text}` / `final {text}` / `error {code}`
- **macOS** (`SFSpeechRecognizer(locale: ko-KR)` + `AVAudioEngine`)
  - `contextualStrings` 에 66권 이름·`장`·`절`·`편` 을 넣어 책 이름 인식률을 올린다
  - 가능하면 `requiresOnDeviceRecognition = true`(음성이 애플 서버로 안 나간다, 시간 제한 없음). 한국어 온디바이스가 안 되는 Mac 은 서버 인식 — 요청 하나가 약 1분이라 끝나면 바로 새 요청으로 잇는다
  - Info.plist `NSMicrophoneUsageDescription`·`NSSpeechRecognitionUsageDescription` 추가(지금 샌드박스는 꺼져 있어 entitlement 는 불필요)
- **Windows** (`Windows.Media.SpeechRecognition.SpeechRecognizer`, ko-KR)
  - 받아쓰기(dictation) 제약은 Windows '온라인 음성 인식' 설정을 켜야 해서, **문법 제약(SRGS: 책 이름 + 숫자 + 장/절/편/부터/까지)** 을 쓴다 — 오프라인으로 돌고, 설교 다른 말에는 잘 안 걸린다. 확신도 `Medium` 미만은 버린다
  - 한국어 음성 언어 팩이 필요하다(OCR 의 한국어 OCR 기능과 같은 처지). 없으면 `isAvailable` false → 설치 안내
  - OCR 채널처럼 WinRT 비동기는 작업 스레드에서, 결과는 메시지 창으로 UI 스레드에 넘긴다(`ocr_channel.cpp` 그대로 따라 한다)

## 4. 위험

- **오인식으로 엉뚱한 구절이 들어감** — 관객 화면은 안 바뀌고(넣기만) 되돌리기가 있어 사고는 작다. 그래도 자동으로 띄우면 위험하므로 기본은 넣기만
- **설교자가 지나가듯 말한 구절까지 다 들어감** — 중복 막기로 줄지만 썸네일이 길어질 수 있다. 결정 항목 B 로 줄인다
- **설교 음성을 어떻게 받나** — 설교단 무선 마이크 소리가 PC 에 안 들어오면 노트북 마이크는 스피커 울림을 듣는다(인식률 낮음). 음향 콘솔 AUX → PC 라인 입력이 가장 좋다. 입력 장치 고르기는 1차에선 OS 기본 입력만
- **macOS 서버 인식이면 음성이 애플로 나간다** — 안내창에 적는다. 온디바이스가 되면 나가지 않는다
- 서명 없는 앱이라 업데이트할 때마다 macOS 가 마이크 권한을 다시 물을 수 있다(확인 필요)

## 5. 결정 필요

| | 질문 | 기본안(추천) |
|---|---|---|
| A | 누가 말하나 — **설교자 목소리를 계속 듣기** vs **운영자가 버튼 누르고 말하기** | 계속 듣기(요청하신 대로). 다만 운영자용 '누르고 말하기'(단축키 누르는 동안만)도 같은 엔진이라 거의 공짜로 같이 넣을 수 있다 |
| B | 들으면 바로 넣기 vs 후보로만 띄우고 Enter 로 넣기 | **바로 넣기 + 되돌리기**(요청하신 대로). 오인식이 잦으면 설정으로 '확인 후 넣기' 추가 |
| C | 넣고 관객 화면도 바로 넘길까 | **안 넘긴다.** 상태 줄의 '바로 띄우기' 버튼 하나로 넘긴다 |
| D | "로마서 8장" 처럼 절 없이 장만 말하면 | 장 전체를 나눠 넣는다(설교 본문 봉독일 때가 많다). 대신 페이지 수를 상태 줄에 보여 준다 |
| E | 본문 낭독으로 찾기(`하나님이 세상을 이처럼 사랑하사` → 요 3:16) | **2차로 미룬다.** 기존 본문 검색(`searchVerses`)에 그대로 넘기면 되지만 설교 말 전체가 검색어가 되어 오인식이 많다 |

## 6. 하지 않는 것 (1차)

- 본문 낭독 검색(위 E), 입력 장치 고르기, 영어 등 다른 언어로 말하기, 편집 탭에서 음성 검색
- 클라우드 음성 API(Google·Whisper API 등) — 키 관리·비용·인터넷 의존이 생긴다. OS 내장이 부족하면 그때 whisper.cpp 로컬 모델을 검토한다
