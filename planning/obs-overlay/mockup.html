OBS 브라우저 소스 자막 — 화면 목업

앱에서 페이지를 넘기면 OBS 자막이 같이 넘어간다. 바탕은 투명(크로마키 없음). 노란 테두리(NEW)는 새로 생기는 컨트롤이다.
예시 가사는 목업용으로 지어낸 글, 성경은 시편 23:1(개역개정 · KJV) 예시. 주소·포트(8766)는 기술 설계의 제안값이다.

s1. 앱 바 — 'OBS' 버튼

'PPTX 저장' · 모니터 선택 · OBS · 발표 시작 — 화면을 내보내는 '출력' 묶음에 둔다. 아이콘(방송 탑) + 짧은 글 OBS. 상태 점은 아이콘 오른쪽 위: 꺼짐 = 없음 · 켜짐·연결 없음 = 회색 · 연결됨 = 초록 · 오류 = 빨강. 툴팁에 상태 문장.

s4. OBS 합성 예시 — 찬양 (원본 + 보조 2줄씩), 외곽선 vs 반투명 띠

예배 카메라 화면(흉내) 위에 1920×1080 투명 페이지를 통째로 얹은 모습. 자막 덩어리는 아래 기준선에서 위로 자란다 — 줄 수가 달라도 아래 선이 고정이라 방송 화면이 덜 흔들린다.

s5. OBS 합성 예시 — 성경 (참조 + 본문 + 보조 역본)

참조(시편 23:1)는 덩어리 맨 위에 작게, 참조 색(기본 금색). 본문은 관객 화면 성경과 같게 왼쪽 정렬, 덩어리 자체는 가운데. 성경은 줄이 길어 폭(좌우 여백 안)에서 자동 줄바꿈되고, 덩어리가 '최대 높이'(30%)를 넘으면 글자를 같은 비율로 줄인다.

s6. 발표 보기 머리줄 — 'OBS' 칩

OBS 자막이 켜져 있을 때만 머리줄 오른쪽 끝(툴바 뒤)에 나온다. 누르면 작은 메뉴: 잠시 숨기기 / 설정 열기. 숨긴 동안은 주황 OBS 숨김 — 예배 중 설정 창을 안 열고 자막만 빨리 끈다.
