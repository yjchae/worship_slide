# 디자인: 슬라이드 편집 창 — PowerPoint 방식 (캔버스 안 편집 · 2줄 리본 · 도형 · PPTX 가져오기)

목업: `mockup.html` (화면 s1~s6 세로), 캡처: `screens/s1.png`~`s6.png` (Playwright Chromium, deviceScaleFactor 2, 대화상자 1368×820).
색은 지금 밝은 테마 그대로 — primary 차콜 `#2C2E35`(주 버튼), point 슬레이트 블루 `#4D5E82`(선택 테두리·손잡이·켜진 버튼·포커스), 바탕 무채색. 경고 아이콘만 옅은 노랑. 초록·와인 없음.
(참고: 기본 테마 primary 는 보라가 아니라 차콜이다. 보라 primary 는 '라벤더' 테마 `#43377A` 뿐이고, 목업은 `colorScheme` 만 쓰므로 테마를 따라간다.)

## 화면 흐름
- s1 아무것도 안 고름 → '글 상자' 누름 → 가운데 새 상자 + 바로 편집(s2) → ESC = 편집 끝(상자 고른 채) → ESC = 고르기 해제(s1)
- s1 → '도형 ▾'(s3) → 종류 고름 → 가운데에 생기고 고른 상태(s4) → 더블클릭·Enter·F2 = 도형 안 글 편집(줄 2 는 '도형 서식' 그대로)
- 아무 요소 → Shift/⌘·Ctrl+클릭 또는 빈 곳 끌기 → 여러 개(s5) → '맞춤 ▾'
- (3단계) 가져오기 메뉴 'PPT 를 편집 페이지로 가져오기…' → 파일 → 진행 창 → 결과 창(s6) → '콘티에 담기'

## 화면별 구성
- 공통 머리: 제목('슬라이드 편집 페이지' / '… 수정' / '틀 편집') → 리본 줄 1 → 리본 줄 2 → 캔버스 | 오른쪽 패널(폭 300) → 아래 줄(메시지·취소·확인). 리본 두 줄은 각각 높이 42 고정이고 **줄 2 는 늘 자리를 차지한다**(고르기를 바꿀 때 캔버스가 위아래로 튀지 않게).
- 줄 1 '삽입·정렬'(왼쪽부터): 그림 · 붙여 넣기 · 글 상자 · 도형 ▾ | 복제 · 삭제 | 맨 앞으로 · 앞으로 · 뒤로 · 맨 뒤로 | 맞춤 ▾ | 되돌리기 · 다시 하기. 삽입 네 개와 맞춤만 글자 라벨, 순서·되돌리기는 아이콘+툴팁(지금 단축키 툴팁 그대로).
- 줄 2(맨 앞에 작은 이름표):
  - 아무것도 안 고름(s1) / 그림만 고름: 이름표 '글자 서식' 회색 + 모든 칸 비활성 + "글 상자나 도형을 고르면 쓸 수 있습니다."
  - 글 상자(s2): '글자 서식' = 글꼴(FontFamilyPicker) · 크기(입력+목록) · 가+ / 가− · B I U S · 글자 색(가 + 색 막대 ▾) | 왼쪽·가운데·오른쪽 정렬 | 글머리 · 번호 | 서식 지우기
  - 도형(s4): '도형 서식' = 채우기(색 칸 ▾, 메뉴 첫 줄 '채우기 없음') · 투명도(슬라이더 0~100% + 숫자) · 테두리(색 ▾, '테두리 없음') · 두께(pt ▾) | 세로 맞춤 위·가운데·아래 | 글자 서식 묶음(서식 지우기는 아이콘만). 선·화살표는 채우기·세로 맞춤·글자 묶음 비활성.
  - 여러 개(s5): 고른 것 중 글 상자·도형이 있으면 그 종류의 서식 줄, 둘 다 있으면 '글자 서식'(공통인 것만). 적용은 해당 종류에만.
- 캔버스: 고름 = point 실선 + 손잡이 8개(하나일 때만, 선·화살표는 양 끝 2개). 편집 중 = point 점선 + 바깥 6px 옅은 띠(이 띠를 끌면 옮기기). 여러 개 = 각자 실선, 손잡이 없음, 전체를 감싸는 옅은 점선.
- 캔버스 아래 상태 줄: 상황별 한 줄(아래 '문구').
- 오른쪽 패널: 안 고름 = 페이지 이름·페이지 배경(지금 그대로) / 글 상자·도형 = 종류 이름 + 위치·크기 X·Y·폭·높이(1920×1080 기준 숫자) / 그림 = 지금 그림 설정 + 위치·크기 / 여러 개 = 안내문만.
- s3 도형 메뉴: 머리 '도형 넣기', 사각형 · 둥근 사각형 · 타원 | 선 · 화살표(아이콘+이름).
- s5 맞춤 메뉴: 머리 '고른 요소 N개 기준'(하나면 '슬라이드 기준'), 왼쪽·가운데·오른쪽 | 위쪽·중간·아래쪽 맞춤.
- s6 결과 창(폭 600): 제목, 파일 이름, 큰 줄 'N장 중 M장', 항목 줄(아이콘·이름·설명·개수 오른쪽): 그림으로 둔 요소 / 빠진 꾸밈 / 없는 글꼴(이름 나열) / 16:9 가 아님(몇 번째 장) / 숨긴 슬라이드. 0인 줄은 숨긴다. 아래 안내 한 줄, 버튼 '담지 않기' · '콘티에 담기 (M장)'.

## 상태
- 빈 값: 빈 글 상자는 편집이 끝나면 점선 '글 상자' 자리표시(지금 그대로). 섞인 값 — 크기 칸 빈칸, 글자 색 막대 점선 테두리, B/I/U/S·정렬은 꺼진 모양, 글꼴 빈칸.
- 없는 글꼴: 글꼴 칸에 이름 그대로 + 뒤에 '(없는 글꼴)' 회색, 목록 맨 위에도 같은 표시.
- 로딩: 붙여 넣기 중 버튼 자리 작은 원형 진행(지금 그대로). '확인' 굽는 중 = 버튼 안 진행 + 메시지 '페이지를 만드는 중…'(지금 그대로). PPT 가져오기 진행 창: "'파일 이름' 을 읽는 중… (슬라이드 n / N)" + '취소'.
- 오류: 굽기 실패 = 아래 줄 빨간 글 '페이지 그림을 만들지 못했습니다. 다시 확인을 눌러 주세요.'(지금 그대로). 가져오기 — 편집 가능 0장이면 결과 창 큰 줄 '편집 페이지로 만들 수 있는 장이 없습니다' + 주 버튼 '닫기'만. LibreOffice·PowerPoint 둘 다 없으면 기존 LibreOffice 설치 안내창. 파일을 못 열면 'PPT 파일을 열지 못했습니다. 파일이 PowerPoint 에서 열리는지 확인해 주세요.'

## 문구
- 상태 줄: 안 고름 "그림 1 · 글 상자 2 · 도형 0   더블클릭: 글 고치기 · Shift/⌘+클릭: 여러 개 고르기 · 빈 곳 끌기: 범위로 고르기" / 편집 중 "글 편집 중   ESC: 편집 끝내기 · 테두리를 끌어 옮기기 · 리본 서식은 고른 글자에만" / 도형 "도형 1개 고름   더블클릭·Enter: 안에 글 쓰기 · 방향키: 옮기기(Shift = 크게)" / 여러 개 "요소 3개 고름 (글 상자 2 · 그림 1)   함께 끌어 옮기기 · Delete: 모두 지우기 · ⌘D: 모두 복제" (Windows 는 Ctrl+)
- 패널(여러 개): "요소 3개를 골랐습니다 / 함께 옮기기·복제·삭제·순서·맞춤이 됩니다. 크기는 하나만 골랐을 때 바꿉니다. / 리본 글자 서식은 고른 것 중 글 상자 2개에만 적용됩니다."
- 툴팁: '도형 넣기', '맞춤', '한 단계 크게', '한 단계 작게', '굵게 (⌘B)', '기울임 (⌘I)', '밑줄 (⌘U)', '취소선', '글자 색', '왼쪽 정렬'·'가운데 정렬'·'오른쪽 정렬', '글머리 기호', '번호 매기기', '서식 지우기', '채우기 색', '투명도', '테두리 색', '테두리 두께', '위에 맞춤'·'가운데에 맞춤'·'아래에 맞춤'
- s6 전체 문구는 목업 그대로.

## 키보드
- 고름: Enter·F2 = 편집 시작(커서 글 끝), Delete = 지우기, ⌘/Ctrl+D 복제, 방향키 옮기기, ESC 고르기 해제, Tab = 다음 요소 고르기(뒤 요소 순).
- 편집 중: 글자·Delete·Backspace·⌘/Ctrl+A·방향키는 글에만, ⌘/Ctrl+B/I/U = 서식, ESC = 편집 끝, ⌘/Ctrl+Z 는 Quill 안이 아니라 창 되돌리기(편집 묶음 한 번)인지 — **확인 필요**(결정 2).
- 메뉴(도형·맞춤): 열면 첫 항목에 포커스, ↑↓ 이동, Enter 실행, ESC 닫고 버튼으로 포커스.
- Tab 순서: 리본 줄 1 → 줄 2 → 캔버스 → 패널 → 아래 줄(지금 NumericFocusOrder 그대로 하나 추가).

## 접근성
- 아이콘만 있는 버튼은 툴팁 = 스크린리더 이름(위 목록). 켜진 토글(B·정렬·세로 맞춤)은 `Semantics(toggled:)`.
- 비활성은 색만이 아니라 실제 `onPressed: null`.
- 대비: 리본 글자 ink `#1C1C21`/흰 바탕, 비활성 `#B9BAC2` 는 비활성이라 예외. 선택 테두리 point 는 어두운 슬라이드 위에서 흐릴 수 있어 손잡이는 흰 채움+point 테두리.
- 섞인 값 빈칸은 스크린리더에 '여러 값'으로 읽힌다.
- 포커스 표시: point 2px 바깥선.

## 화면 수용 기준
- [ ] 리본은 두 줄이고, 아무것도 안 고름·글 상자·도형·여러 개를 오갈 때 캔버스 위쪽 끝 y 좌표가 바뀌지 않는다.
- [ ] 아무것도 안 고르면 줄 2 의 모든 컨트롤이 `onPressed: null` 이고 "글 상자나 도형을 고르면 쓸 수 있습니다." 가 보인다.
- [ ] 글 상자를 고르면 줄 2 이름표가 '글자 서식', 도형을 고르면 '도형 서식' 이다. 오른쪽 패널에 글 입력칸이 없다.
- [ ] 크기가 다른 글자를 함께 고르면 크기 칸이 비어 있고, 같으면 그 숫자가 보인다(글꼴·색도 같은 규칙).
- [ ] 편집 중 상자는 점선 테두리이고 손잡이가 없다. 고른 상자는 실선 + 손잡이 8개, 선·화살표는 2개다.
- [ ] '도형 ▾'를 열면 사각형·둥근 사각형·타원·선·화살표 5개가 이 순서로 있고, 키보드만으로(↓·Enter) 넣을 수 있다.
- [ ] 테두리 '없음'이면 두께 칸이 비활성이다. 선·화살표를 고르면 채우기·세로 맞춤·글자 묶음이 비활성이다.
- [ ] 여러 개를 고르면 손잡이가 없고, 맞춤 메뉴 머리가 '고른 요소 N개 기준'(하나면 '슬라이드 기준')이다.
- [ ] 결과 창의 각 줄 개수가 Python `layout` 출력의 합과 같고, 0인 줄은 나오지 않는다. '담지 않기'를 누르면 콘티가 바뀌지 않는다.
- [ ] 모든 아이콘 버튼에 툴팁이 있다(위젯 테스트에서 `find.byTooltip`).

## 결정 필요 항목
1. 줄 2 가 비었을 때 — A: 글자 서식을 비활성으로 보여 자리 유지 / B: 줄 2 숨김 · 추천: A (고를 때마다 캔버스가 42px 씩 튀지 않는다)
2. 편집 중 ⌘/Ctrl+Z — A: 창 되돌리기로 편집 중 친 글까지 한 묶음 되돌림 / B: Quill 안 되돌리기(글자 단위), 편집 끝난 뒤엔 창 되돌리기 · 추천: B (PowerPoint·워드와 같고 몇 글자만 지우려다 전부 사라지지 않는다). 기획서 '편집 묶음 한 번 기록'과 충돌하지 않는다 — 끝낸 뒤 묶음은 그대로.
3. 결과 창 시점 — A: 담기 전에 보여 주고 '콘티에 담기'/'담지 않기' / B: 담은 뒤 알림만(기획서 흐름) · 추천: A (없는 글꼴·16:9 아님을 보고 그림으로 가져오기로 돌릴 수 있다)
4. 오른쪽 패널의 위치·크기 숫자 — A: 둔다 / B: 없앤다(기획 결정 4) · 추천: A (패널 자리가 남고, 여러 요소를 같은 높이로 맞출 때 쓴다). 구현을 줄이려면 B 도 문제없다.
5. 맞춤 '간격 같게'(배분) — 이번엔 뺐다 · 추천: 빼기 (기획 범위 밖, 요청 오면 메뉴 아래 두 줄 추가)
6. 숨긴 슬라이드 줄 — 기획 결정 8(A 건너뛰기)이면 결과 창에 '건너뜀 n장'으로 알림 · 추천: 알림 둠 (장 수가 안 맞아 보이는 혼란 방지)
