# 확정 결정 (2026-11-24, 사용자 "추천대로 1단계 시작")

1. 편집 중 ⌘/Ctrl+Z = 글자 단위(Quill 안 되돌리기). 편집 밖에서는 창 되돌리기(PageEditHistory). 편집을 끝내면 그 편집 전체가 창 되돌리기 한 묶음.
2. 굽기 렌더를 편집기와 같은 규칙으로 바꾼다(tech-frontend 안). `_renderVersion` 을 올리고, 옛 페이지 글머리 줄바꿈이 조금 달라지는 것은 받아들인다. plan 수용 기준 "같은 PNG 경로"는 "같은 모양(글머리 줄 제외)"으로 바꾼다.
3. PPTX 가져오기(3단계): 표·차트·회전 등은 두 번 굽기로 배경 그림에.
4. 4:3 슬라이드: 양옆을 비워 16:9 로 넣는다.
5. 가져오기 결과 창: 콘티에 담기 전에 보여 주고 '콘티에 담기 / 담지 않기'.
6. 옛 앱에서 도형 사라짐은 안내로. 이번 판부터 `PageUnknownElement`(모르는 type 을 JSON 그대로 보존·왕복, 캔버스엔 안 그림)를 넣는다.
7. 3단계 전에 사용자에게 실제 교회 PPT 견본을 받는다(미수령).
8. 팀 내 통일: 도형 JSON 키는 plan.md 이름(`shape`, `fill`, `fill_alpha`, `stroke`, `stroke_width`, `radius`, `flip_h`, `flip_v`, `valign`). 오른쪽 패널 폭 280, 위치·크기 숫자 칸은 남긴다(design 안). 가로선(높이 0) 저장은 2단계에서 선·화살표만 clamp 예외.
