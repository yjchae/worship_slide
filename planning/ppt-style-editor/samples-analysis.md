### 글꼴

- 테마 글꼴: A·B·C 는 major/minor 모두 latin '맑은 고딕', D 는 latin 'Lucida Sans Unicode' + **ea 칸이 비어 있고 Hang 언어 글꼴이 '맑은 고딕'**.
  → 한글 run 은 `ea` 가 비면 `<a:font script="Hang">` 을 써야 한다(구현함). 기본 python-pptx 템플릿도 같은 모양.
- 글자에 직접 지정한 글꼴(같은 글꼴이 latin·ea 에 모두 들어 있음): A 6종, B 4종, C 10종, D 3종 — 대부분 상업·무료 한글 글꼴(210 시리즈, 배달의민족, THE정고딕 등).
- 테마 글꼴 참조 `+mj-lt`·`+mn-ea`·`+mj-ea`(latin 칸에 `+mj-ea` 를 넣은 경우도 있음 — D) — 모두 테마에서 푼다.
- `cs` 칸(`+mn-cs`)은 한글과 무관해 무시.

### 관찰 → 구현에 반영한 것

1. **글 효과(특히 네온 glow)가 아주 흔하다**(B 108곳, C 60곳). 결정 6 A대로 효과는 버리고 글은 요소로 둔다 → `effects_lost` 로 센다.
   B·C 에서 `<a:ln><a:noFill/>` 윤곽선 44·35곳은 "윤곽선 없음"이라 효과로 세지 않는다.
2. **말풍선(wedgeEllipseCallout)·구름 말풍선이 사진 위에 얹힌 꼴**이 많다(C 16). 말풍선은 지원 모양이 아니라 배경 그림이 되는데,
   그러면 요소로 바꾼 사진이 말풍선 위에 그려져 겹침 순서가 뒤집힌다 → **"그림으로 남는 도형이 위에서 덮는 그림·도형도 같이 그림으로"** 규칙을 넣었다(`covered`).
   글 상자는 편집이 목적이라 덮여 있어도 요소로 둔다(D 에서 작은 장식이 제목 상자 범위에 걸치는 일이 12번 있었다).
3. **그라데이션 채우기 도형**(B 16·D 13 — 사진 위 반투명 띠·도식 원) → 배경 그림.
4. **4:3 견본(D)이 실제로 있다** → 결정 4대로 16:9 안 가운데(양옆 검정 여백)로 넣는다. D 는 `wrap="none" + spAutoFit` 상자가 44개 —
   PowerPoint 글꼴 폭에 꼭 맞춘 상자라 앱 글꼴이 조금만 넓어도 줄이 바뀐다 → 이런 상자는 정렬 기준을 두고 폭을 30% 넓혔다(`ponytail:` 주석).
5. **줄 간격(lnSpc)·문단 간격**(B·C 각 27~28 문단)은 앱 글 칸에 없다 — 버린다. 줄 사이가 좁아 보일 수 있다(아래 4장).
6. 자리표시자는 적다(장당 0~1). 상속은 rPr 에 크기가 없는 run 이 A 39%·C 23% 라 **상속 풀기가 꼭 필요**했다(제목 크기·글머리 buNone 등).
7. 표·차트·SmartArt·숨긴 슬라이드는 이 4개에 **없다** — 분류는 python-pptx 로 만든 견본(`test_pptx_layout.py`)으로만 확인했다.
8. B·C 는 '미리보기/인쇄만' 심은 글꼴이 있어 macOS 에서 PowerPoint 를 건너뛰고 LibreOffice(+심은 글꼴 풀기)로 굽는다(기존 render 규칙 그대로). A·D 는 PowerPoint 로 굽는다.

### 눈으로 비교한 것 (원본 PDF 렌더 vs 배경 PNG + 요소를 Pillow 로 대충 그린 미리보기, 스크래치)

- 위치·크기: 글 상자·도형·그림 자리가 원본과 겹쳐 보인다(D 4:3 여백 포함). 요소로 바꾼 도형은 배경 PNG 에서 빠져 있고, 회전·그라데이션·말풍선은 배경에 남아 있다.
- 다른 점(앱이 못 하는 것): 원본 글꼴이 없으면 줄바꿈이 달라진다(C 제목 상자에서 한 줄 → 두 줄), 줄 간격이 원본보다 좁다(B·D), 네온 효과가 빠져 사진 위 글이 덜 읽힌다(B·C).
- 숨긴 슬라이드 실험(python-pptx 3장 중 1장 숨김): **LibreOffice·PowerPoint(이 맥) 둘 다 PDF 에서 숨긴 장을 뺀다**(3장 → 2쪽).
  그래서 두 번 굽기 사본은 모든 장의 `show` 를 지워 다 굽고 쪽 N = 슬라이드 N 으로 맞춘다(숨긴 장 배경은 버린다). 쪽 수가 다르면 가져오기를 실패시킨다.

## 3. 미확인

- Windows(PowerPoint COM·LibreOffice)에서의 두 번 굽기·숨긴 장 처리 — 이 맥에서만 돌렸다.
- Flutter 데스크톱이 시스템 글꼴을 한글 이름('배달의민족 도현')으로 찾는지 — Python 은 name 테이블의 모든 언어 이름으로 '깔려 있음'을 판정한다(프론트 확인 필요).
- 표·차트·SmartArt 가 든 실제 PPT, 숨긴 슬라이드가 든 실제 PPT — 견본에 없다.
- `.ppt`(옛 형식) 입력 — LibreOffice 로 pptx 로 바꾼 뒤 같은 길이지만 실제 파일로 안 돌렸다.
