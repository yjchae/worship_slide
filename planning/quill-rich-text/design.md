# 디자인: 글 상자 부분 서식(Quill) 패널 정리

근거 코드: `page_editor_dialog.dart` `_textProperties`(1445~), 패널 폭 `SizedBox(width: 280)`(910행) + 안쪽 `padding 16`(1354행) → **도구줄이 쓸 수 있는 폭은 약 248px**.
렌더 규칙: `page_rich_text.dart`(`pageTextSpan`) — 글자별 속성은 `bold==true`·`italic`·`underline`·`strike`·`color`·`size`(pt, 540pt 기준)만 읽고, 줄 정렬은 상자 하나(`align`), 목록은 '• '·'N. ' 평문 접두.

## 화면 흐름
1. 캔버스에서 글 상자를 고른다(또는 '글 상자 추가') → 오른쪽 패널에 글 상자 속성이 뜬다.
2. 패널 위에서 아래로: 글 입력칸 → 서식 도구줄 → (구분선) 상자 전체 설정(크기·색·굵게·정렬·글꼴) → 삭제/순서 등 기존 항목.
3. 글자를 드래그해 고른 뒤 도구줄을 누르면 **고른 글자만** 바뀐다. 아무것도 안 고르고 상자 전체 설정을 바꾸면 **기본값**이 바뀐다.
4. 상자 전체 설정을 바꿨는데 직접 서식을 준 글자가 남아 있으면 패널 아래 안내 줄이 그 사실과 되돌릴 길을 알려 준다(아래 추천안).
5. '완료'는 지금과 같다(창 안에서 굽고, 실패하면 창 유지).

## 문제 (1) (2) 해결안

### 원칙(사용자에게 보이는 규칙 한 줄)
"**상자 설정은 기본값, 도구줄은 고른 글자만.** 도구줄로 직접 바꾼 글자는 상자 설정보다 우선합니다."

### 추천안 A — 구역 이름 + 직접 서식 안내 줄(파괴 없음)
- 도구줄 위에 소제목 `고른 글자` (고른 글자가 없으면 `고른 글자 (글자를 드래그해 고르세요)`).
- 상자 단위 컨트롤 묶음에 소제목 `상자 전체 기본값`. 슬라이더 라벨은 `기본 글자 크기 48pt`, 색 라벨은 `기본 글자 색`, 굵게 툴팁은 `기본 굵게`.
- 기본값을 바꿨고 그 속성(크기/색/굵게)을 직접 지정한 글자 구간이 있으면, 컨트롤 묶음 아래에 안내 줄 표시:
  `직접 바꾼 글자 3곳은 그대로입니다. [모두 기본값으로]`
  - 버튼 = 글 전체에서 크기·색·굵기 직접 지정만 제거(서식 지우기와 달리 기울임·밑줄·취소선·목록은 유지). 한 번 눌러 적용, 편집 창 되돌리기(⌘/Ctrl+Z)로 복구. 확인창 없음.
  - 안내 줄은 직접 지정이 0곳이면 숨김. 크기·색·굵게 중 어느 것이 남았는지는 `크기 2곳 · 색 1곳`처럼 적어도 된다(구현 부담 크면 `3곳`만).
- **굵게 해제 문제**: 상자 기본이 굵게일 때 일부만 풀 수 있어야 한다. 도구줄 굵게 버튼은 "고른 글자의 **실제 굵기**"를 보여 주고(기본 굵게면 눌린 상태), 누르면 `bold:false`를 명시로 저장한다. → **렌더러(`_inlineStyle`)가 `bold==false`를 w400으로 읽도록 개발 변경 필요**(지금은 `==true`만 읽어 무시됨). 기본이 굵지 않을 때 `bold:true`는 그대로.
  (크기·색은 직접 값이 항상 이기므로 별도 처리 없음.)
- 왜 추천: 기존 상자 컨트롤·저장 형식 유지, 데이터를 몰래 지우지 않고, 헷갈리는 순간(슬라이더를 올렸는데 안 바뀜)에 바로 이유를 알려 줌.

### 대안 B — 상자 컨트롤이 부분 서식을 덮어씀
기본 크기·색·굵게를 바꾸면 해당 속성의 직접 지정을 전부 제거. 규칙은 단순하지만 공들여 입힌 강조가 슬라이더를 만지다 사라진다(되돌리기로만 복구). 비추천.

### 대안 C — 적용 대상 토글 `[상자 전체 | 고른 글자]`
컨트롤을 하나로 합치고 토글로 대상 전환. 컨트롤 수가 줄지만 모드를 잊으면 오작동, 패널 폭 부담. 비추천.

### 문제 (2) 입력칸이 실제 모습과 다름 — 추천
- 입력칸에 **슬라이드와 같은 글꼴(`e.fontFamily`)·기본 색(`e.color`)·기본 굵기**를 적용하고, 입력칸 바탕은 **현재 페이지 배경 색**(배경 그림은 안 깔고 색만)으로 칠한다. 흰 글자가 흰 패널 위에서 안 보이는 것 방지. 테두리는 지금처럼 `cs.outline`.
- 글자 크기는 슬라이드 기준 pt(540pt = 슬라이드 높이)를 입력칸 폭에 맞춰 **일정 배율로 축소해 비율만 보이게** 한다(예: 배율 0.3 안팎, 가장 큰 글자가 입력칸을 못 넘게 상한). Quill 은 `size` 를 px 로 그리므로 `MediaQuery(textScaler: TextScaler.linear(k))` 로 감싸는 방식이 후보 — **확인 필요**(Quill 이 `textScaler` 를 따르는지 코드로 아직 안 봄; 안 따르면 `customStyles` 로 대체).
- 입력칸 아래 한 줄 캡션: `미리보기는 줄여서 보여 줍니다. 실제 크기는 캔버스에서 확인하세요.`
- 도구줄 크기 칸: 라벨 `크기`, 표시값은 고른 글자의 실제 크기 `48pt`, 글자마다 다르면 `혼합`, 아무것도 안 골랐으면 기본값 `48pt`. 툴팁 `글자 크기 (슬라이드 기준 pt)`. (지금은 `defaultDisplayText` 가 상자 기본 크기만 보여 줘 직접 지정한 글자를 골라도 틀린 값이 나올 수 있음 — 확인 필요.)
- 입력칸 높이: 150px 고정 → 최소 120, 글이 늘면 최대 220까지 늘고 그 뒤엔 안쪽 스크롤.

## 화면별 구성 (위치·요소·동작)

패널 폭 280 (안쪽 248). 와이어프레임(추천안 A, 패널 폭 280 유지 시):
```
┌ 글 상자 ─────────────────────┐
│ 고른 글자                     │
│ [B][I][U][S] [A▾] [48pt ▾]    │  ← 도구줄 1줄차
│ [•][1.] [서식 지우기]          │  ← 2줄차 (접힘)
│ ┌───────────────────────────┐ │
│ │ 오늘의 말씀                │ │  ← 입력칸: 슬라이드 글꼴·색·배경색,
│ │ 요한복음 3:16              │ │     크기는 줄여서(비율 유지)
│ └───────────────────────────┘ │
│ 미리보기는 줄여서 보여 줍니다. │
│ ─────────────────────────── │
│ 상자 전체 기본값              │
│ 기본 글자 크기 48pt           │
│ [━━━━●━━━━━━━━━] [ 48 ]       │
│ 기본 글자 색                  │
│ ● ● ● ● ● ● [직접 고르기]     │
│ [B] [왼쪽|가운데|오른쪽]       │
│ 글꼴 [Pretendard ▾]           │
│ ⓘ 직접 바꾼 글자 3곳은 그대로  │
│   입니다. [모두 기본값으로]    │
└───────────────────────────────┘
```
- 입력칸 위치: 지금은 도구줄(위)→입력칸(아래). 추천은 **도구줄을 입력칸 위에 그대로 두고** 순서는 유지(코드 변경 최소). 안내 문구 1줄은 소제목으로 대체해 삭제.
- 도구줄 구성 변경(추천): `showUndo/showRedo=false`로 뺀다 — 편집 창 자체 되돌리기와 둘이 되어 어느 쪽이 어느 변경을 되돌리는지 헷갈림(어느 쪽이 Ctrl+Z 를 받는지 **확인 필요**). 남는 버튼: 굵게·기울임·밑줄·취소선·색·크기·글머리·번호·서식 지우기 = 9개.
- '서식 지우기' 툴팁은 `고른 글자의 서식 지우기`(기본값·정렬은 안 바뀜을 분명히).
- 정렬(3): 상자 단위만 지원이 현재 한계. 정렬 3택 라벨을 `상자 정렬`로 바꿔 한계를 드러낸다. 줄별 정렬은 이번 범위 밖(렌더러가 줄 정렬을 모름 → 확인 필요/후속).
- 목록(3): 미리보기·굽기는 '• ' 평문 접두라 줄바꿈 시 내어쓰기가 안 된다. 최근 커밋 "내어쓰기 추가" 와의 관계는 **확인 필요**(`page_rich_text.dart` 에 내어쓰기 처리가 아직 안 보임). 입력칸은 Quill 이 들여쓴 목록으로 보이므로 슬라이드 결과와 다를 수 있음 → 캡션에 `목록 기호는 슬라이드에서 글머리 문자로 표시됩니다.` 를 목록이 있을 때만 표시(대안: 입력칸에서도 같은 접두로 표시).
- 크기 선택지(4): 도구줄 드롭다운 9단계(24~120)는 유지하되 맨 위에 `기본값으로`(= size 속성 제거) 항목을 둔다. 임의 값은 상자 크기 칸처럼 숫자 직접 입력이 필요하면 후속 — 지금은 **결정 필요 3번**.

### 패널 폭에서 도구줄이 몇 줄로 접히나(추정)
- 가용 248px. Quill 기본 아이콘 버튼은 아이콘 14px × 1.77 ≈ 25px + 간격 4px ≈ 29px (flutter_quill 11.6.0 기본값 기준, 실제 렌더로는 **미확인**). 크기 드롭다운은 ‘48pt ▾’ 로 대략 70~80px.
- 현재 구성(되돌리기·다시 실행 포함 11개 + 드롭다운): 약 11×29 + 80 ≈ 400px → **2줄**(248 안에 8~9개씩) , 드롭다운 위치에 따라 **3줄**이 될 수 있음. 도구줄만으로 약 60~90px 를 차지해 입력칸 150px 와 합치면 패널 세로 약 250px, 아래 상자 컨트롤이 화면 밖으로 밀려 스크롤이 필요해짐(편집 창 최소 높이에서 특히).
- 추천 구성(되돌리기 2개 제거, 9개 + 드롭다운): 약 9×29+80 ≈ 340px → **2줄**. 패널을 320으로 넓히면 가용 288px → 2줄 유지(1줄은 불가). 폭 확장은 캔버스가 줄어드는 비용이 있어 **결정 필요 2번**.
- `multiRowsDisplay:true` 라 접힘 자체는 문제없지만 줄 사이 구분이 없어 어디까지가 한 묶임인지 안 보임 → `showDividers:false` 를 유지하되 도구줄 한 줄 높이를 고정하지 말 것(접힘 시 입력칸이 밀려도 안 겹치게 Column 안에 두기 — 지금 구조는 맞음).
- 패널 전체가 스크롤되는지(`_propertiesPanel` 의 ListView/SingleChildScrollView)는 코드로 끝까지 확인하지 못함 → **확인 필요**.

## 문구
- 소제목: `고른 글자` / `상자 전체 기본값`
- 입력칸 placeholder: `글을 입력하세요`
- 소제목 보조: `글자를 드래그해 고르세요` (선택 없을 때만)
- 캡션: `미리보기는 줄여서 보여 줍니다. 실제 크기는 캔버스에서 확인하세요.`
- 슬라이더: `기본 글자 크기 48pt` / 색: `기본 글자 색` / 정렬: `상자 정렬`
- 안내 줄: `직접 바꾼 글자 3곳은 그대로입니다.` + 버튼 `모두 기본값으로`
- 툴팁(Quill 한국어): 굵게 / 기울임 / 밑줄 / 취소선 / 글자 색 / `글자 크기 (슬라이드 기준 pt)` / 글머리 기호 / 번호 목록 / `고른 글자의 서식 지우기`. Quill 은 `FlutterQuillLocalizations.delegate` 만 override 하고 앱 locale 은 ko 이므로 한국어로 나오는지 **미확인**(Quill 지원 로케일에 ko 가 있는지 확인 필요, 없으면 영어 툴팁이 섞임 → 위 문구를 `tooltip` 옵션으로 직접 지정).
- 크기 드롭다운 첫 항목: `기본값으로`

## 접근성
- 도구줄 버튼 모두 툴팁 = 스크린리더 이름(위 문구). 상태(눌림)는 `isSelected`/semantics toggled 로 전달되는지 **미확인**.
- 포커스 순서: 글 입력칸 → 도구줄 → 상자 컨트롤(현재 패널 `NumericFocusOrder(3)` 안). 편집 창 바깥 `ExcludeFocus` 는 발표 키 보호용이라 여기엔 없음. 입력칸에 커서가 있으면 편집 창의 삭제·화살표 단축키가 글자 편집으로 먹히지 않아야 함(`_textFocus` 를 쓰는 기존 처리 확인 필요).
- 키보드: 입력칸에서 ⌘/Ctrl+B·I·U 는 Quill 기본 단축키가 굵게·기울임·밑줄을 적용. 편집 창 ⌘/Ctrl+Z 와 Quill 내부 undo 가 충돌하지 않는지 **확인 필요**. Tab 으로 입력칸을 빠져나올 수 있어야 한다(Quill 은 Tab 을 들여쓰기로 먹는 설정이 있음 — 확인 필요).
- 대비: 입력칸 바탕을 페이지 배경 색으로 칠할 때 글자 색과 대비가 낮을 수 있다(흰 글자·밝은 배경). 이는 슬라이드 실제 모습이므로 그대로 보여 주는 것이 맞고 캡션이 "슬라이드와 같은 색" 임을 알려야 한다. 테두리는 `cs.outline` 로 구분.
- 색 견본만으로 의미 전달 금지: 기존대로 툴팁에 이름+hex.

## 앱 테마 7종과 Quill 색 (코드로 확인한 범위)
- 확인됨: Quill 에디터 기본 글자 스타일은 `DefaultStyles.getInstance` 가 `Theme.of(context)`·`DefaultTextStyle` 에서 만든다(`default_styles.dart` 298행 부근, 기본 `fontSize 16`·height 1.15 — 기획자 메모의 14px 와 다름, 실제 값은 16px 로 **보인다**). 글자색은 테마를 따르므로 어두운 테마에서도 대체로 읽힌다. 링크·플레이스홀더 등은 `colorScheme.primary/secondary` 를 쓴다.
- 확인됨: 색 선택 대화상자는 `Colors.black` 를 초기 선택으로 쓰고 견본 테두리 `Colors.black45`(`color_dialog.dart` 32·142행) — 어두운 테마에서 테두리가 안 보일 수 있다. 크기 드롭다운의 `defaultItemColor` 는 `Colors.red`(font_size_options.dart 40행, '지우기' 항목만 해당).
- 확인됨: 도구줄 버튼 색은 `iconTheme` 옵션이 없으면 Material 기본 아이콘 버튼 스타일로, `colorScheme` 을 따를 것으로 보이나 **미확인**(렌더 안 해 봄).
- **미확인**: 7개 테마(`AppThemeKind`) 각각에서의 도구줄·팝업·선택 영역 색 대비, 팝업(색·크기)이 `Dialog`/`Overlay` 에서 테마를 상속하는지. 앱 안 `Quill` 사용처가 `app_theme.dart`/`app.dart` 에 없어 별도 테마 지정은 없음(grep 결과 0건).
- 입력칸을 슬라이드 배경색으로 칠하면 테마와 무관하게 "슬라이드 색"이 되므로 이는 의도된 예외다(앱 화면 색 규칙의 예외로 문서화).
- 팝업 색 견본은 Quill 자체 팔레트이고 앱 `_swatches` 와 다르다 → 팔레트를 `_swatches` 로 맞출지 **결정 필요 4번**(설정: `QuillToolbarColorButtonOptions` 의 팔레트 옵션 존재 여부 확인 필요).

## 화면 수용 기준
- [ ] 패널 소제목에 `고른 글자`와 `상자 전체 기본값`이 보이고, 슬라이더·색 라벨에 `기본`이 붙어 있다.
- [ ] 글 일부에 크기를 직접 준 뒤 기본 크기 슬라이더를 올리면, 그 글자는 안 바뀌고 `직접 바꾼 글자 N곳은 그대로입니다.` 안내 줄이 나타난다.
- [ ] `모두 기본값으로`를 누르면 글 전체의 크기·색·굵기 직접 지정이 사라져 슬라이더 값으로 보이고, 기울임·밑줄·취소선·목록은 남는다. ⌘/Ctrl+Z 로 되돌아간다.
- [ ] 상자 굵게가 켜진 상태에서 글 일부를 고르고 도구줄 굵게를 누르면 그 글자만 보통 굵기가 되며, 캔버스 미리보기와 굽기 PNG 모두 같다. 저장·다시 열기 후에도 유지된다.
- [ ] 입력칸의 글꼴·글자 색·바탕색이 상자 글꼴·상자 색·페이지 배경 색과 같다.
- [ ] 입력칸에서 큰 글자와 작은 글자의 크기 비율이 캔버스와 같고, 가장 큰 글자도 입력칸 폭을 넘지 않는다.
- [ ] 도구줄 크기 칸이 고른 글자의 실제 크기(`48pt`)를 보이고, 크기가 섞이면 `혼합`, 선택이 없으면 기본값을 보인다.
- [ ] 도구줄이 패널 폭 안에서 접히며(최대 2줄 목표) 가로 스크롤·잘림이 없고, 아래 상자 컨트롤까지 패널 스크롤로 닿는다.
- [ ] 도구줄 모든 버튼에 한국어 툴팁이 있고, 키보드 Tab 으로 도달·Space/Enter 로 실행된다.
- [ ] 되돌리기 중복 버튼이 없고 ⌘/Ctrl+Z 가 글자 편집·서식 변경을 한 단계씩 되돌린다.
- [ ] 7개 앱 테마 모두에서 도구줄 아이콘·입력칸 테두리·팝업이 보이고 글자가 읽힌다(화면 확인).
- [ ] 글 상자를 바꿔 고르면 입력칸·도구줄·안내 줄이 그 상자 내용으로 갱신된다.
- [ ] 서식 없는 옛 글 상자는 열었다 닫아도 `rich` 가 생기지 않는다(`rich==null` 유지).

## 결정 필요 항목
1. 상자 기본값과 직접 서식 우선순위 — A 직접 서식 우선 + 안내 줄·`모두 기본값으로` / B 기본값 변경이 직접 서식을 지움 / C 적용 대상 토글 · 추천: A (데이터를 지우지 않고 헷갈리는 순간에 이유를 보여 줌, 저장 형식 변화 없음)
2. 속성 패널 폭 — A 280 유지 + 도구줄 9버튼(2줄) / B 320 으로 넓힘 · 추천: A (캔버스를 덜 줄이고, 되돌리기 버튼 제거만으로 2줄이 된다. 실제로 3줄이면 B)
3. 크기 선택지 — A 9단계 유지 + `기본값으로` 추가 / B 숫자 직접 입력칸 추가 / C 단계를 늘림(예: 18~160 12단계) · 추천: A 로 먼저 내고 B 는 사용자가 단계 부족을 말하면 (Quill 크기 드롭다운은 임의 값 입력이 없어 B 는 도구줄 밖 별도 입력칸이 필요, 비용 큼)
4. Quill 색 견본 — A Quill 기본 팔레트 유지 / B 앱 `_swatches` 와 맞춤 · 추천: B (상자 색과 같은 색을 고를 수 있어야 '기본과 같은 색'이 쉽다; 옵션 지원 여부 확인 후)
5. 정렬·목록 — A 이번엔 상자 단위 정렬·평문 접두 유지 + 캡션으로 한계 안내 / B 줄별 정렬·내어쓰기 목록 · 추천: A (렌더러 네 군데가 아닌 굽기 한 곳이라 B 도 가능하지만 입력칸과 슬라이드 모양을 일치시키는 비용이 큼 — 기획 판단)
6. 입력칸 미리보기 방식 — A 같은 글꼴·색·배경에 크기만 일정 배율로 축소 / B 실제 캔버스 위 인라인 편집 · 추천: A (B 는 별도 기획)
7. Quill 도구줄의 되돌리기·다시 실행 — A 제거(편집 창 되돌리기 하나로) / B 유지 · 추천: A (되돌리기가 두 개면 순서가 꼬임; 단 편집 창 undo 가 글자 입력 단위까지 되는지는 확인 필요)
