S3. 성경 절 행의 끌기 손잡이

절 행 맨 왼쪽에 ⠿ 손잡이를 따로 둔다. 체크박스(클릭 = 선택 토글)·절 글 영역(더블클릭 = 담기)과 겹치지 않는 별도 칸이라 제스처 충돌이 없다(추천 12번). 손잡이를 잡고 끌 때만 끌기가 시작된다.

S4. 발표 보기: 성경 역본 바꾸기

자리: 현재 슬라이드 머리줄(현재 슬라이드 번호·제목 줄). 현재 슬라이드가 성경 페이지일 때만 제목 오른쪽에 역본 칩이 나타난다. 곡·PPT·빈 페이지·편집·미디어에서는 칩 자체가 없다. (정확한 줄 위치는 "확인 필요": tech-frontend 가 가리킨 툴바 줄 vs 머리줄 — 이 목업은 머리줄 추천.)

4-C 확인창 (손으로 고친 본문이 있을 때)

역본을 바꾸면 고친 본문이 사라집니다

이 성경 페이지의 본문은 직접 고친 내용이 있습니다. '개역개정' 본문으로 다시 만들면 고친 내용이 덮어쓰입니다. 바꾼 직후 '되돌리기'로 돌릴 수 있습니다.

고친 본문이 없으면 확인 없이 바로 바뀐다. 기본 포커스 = 취소. 모든 성경 항목에도 적용을 켰으면 제목이 "성경 항목 4개의 역본을 바꿀까요?"로, 고친 본문 N개 안내가 붙는다.

키보드 · 접근성

  • 그룹 머리줄 = 포커스 가능(Tab), 역할 '버튼(접힘 상태 expanded/collapsed)'. 스크린리더 이름 "시작곡 그룹, 항목 3개, 펼쳐짐". ←/→ 접기·펼치기(또는 Enter/Space), F2 이름 바꾸기, ⋯ 는 Shift+F10/Menu 키 또는 Tab 으로 별도 포커스.
  • 항목 행 이름 "3번, 곡, 주 은혜임을, 시작곡 그룹". 손잡이 이름 "주 은혜임을 끌어서 옮기기". 끌기를 못 하는 사용자 대안: 손잡이에 포커스 후 Alt+↑/↓ = 한 칸 이동(그룹 경계를 넘으면 안/밖 전환), ⋯ 메뉴의 위/아래 이동은 그룹용. 절 손잡이 Enter = 맨 끝에 담기.
  • 삽입 선·강조는 색뿐 아니라 굵기·배지 글자·외곽선으로 구분(색각 무관). 대비 4.5:1 이상(회색 보조 글 #6b6b73 on 흰색 ≈ 5:1). 삭제 계열은 오류색 + 글자('삭제').
  • 포커스 표시 2px 외곽선, 모든 테마에서 colorScheme.primary. 끌기 결과는 스낵바 글로 안내(스크린리더가 읽음).
  • ESC = 끌기 취소·메뉴·창 닫기. 확인창 기본 포커스 = 취소. 발표 단축키(←/→/Space)는 목록·칩에 포커스가 있어도 기존 규칙(Tab 으로 버튼 위에서도 넘김)이 유지되도록 확인 필요.
  • 색은 하드코딩하지 말고 colorScheme(surface·outlineVariant·surfaceContainerHighest·primary·error)에서 가져온다. 이 목업의 색은 밝은 테마 기준 예시.

화면 수용 기준

  • 편집 탭 목록에 그룹 머리줄(▸/▾·이름·N개·⋯)과 들여쓴 항목 행이 보이고, 그룹 밖 항목은 들여쓰기 없이 보인다.
  • 항목 번호는 접어도 전체 번호가 유지되고, 접힌 머리줄에 '(N개 숨김)'과 번호 범위가 보인다.
  • 머리줄 '그룹 만들기' → 이름 창 → 고른 항목이 들어간 그룹 또는 '0개' 빈 그룹이 생긴다. 같은 이름이면 오류 문구로 막힌다.
  • ⋯ 메뉴에 이름 바꾸기·위로 이동·아래로 이동·그룹 풀기·그룹과 항목 삭제가 있고, 맨 위/맨 아래 이동은 비활성 + 이유가 보인다.
  • 그룹 풀기는 확인 없이 항목을 유지하며 되돌리기가 뜨고, '그룹과 항목 삭제'는 확인창(기본 포커스 취소)을 거친다.
  • 곡 검색 결과를 끌면 콘티 행 사이에 선이 나타나고, 놓으면 그 자리에 담긴다. 선의 들여쓰기로 그룹 안/밖이 구분된다.
  • 그룹 머리줄 아래 절반에 놓으면 그룹 안 맨 앞(접힌 그룹은 맨 끝), 위 절반에 놓으면 그룹 밖. 놓을 수 있는 머리줄은 외곽선 + "'이름'에 넣기" 배지.
  • 콘티 항목을 끌어 그룹에 넣고/빼고, 머리줄 손잡이로 그룹째 옮길 수 있다. 그룹 안에 그룹은 놓을 수 없다(문구 표시).
  • 놓은 항목은 8초 동안 '방금 담음' 배지 + 막대로 강조되고 그 자리로 스크롤된다.
  • 빈 콘티·목록 아래 빈 곳·더블클릭·'담기' 버튼은 모두 맨 끝에 담는다.
  • 성경 절 행 맨 왼쪽에 ⠿ 손잡이가 있고, 체크박스 클릭은 체크만 토글하며 손잡이만 끌기를 시작한다. 체크된 절의 손잡이는 체크 전체를, 안 체크된 절의 손잡이는 그 절만 끈다.
  • 발표 보기 현재 슬라이드가 성경 페이지일 때만 역본 칩이 보이고, 곡·PPT·빈 페이지에서는 보이지 않는다.
  • 드롭다운에서 66권이 아닌 역본은 비활성이며 이유가 항상 보인다.
  • 손으로 고친 본문이 있을 때만 확인창이 뜨고, 없으면 바로 바뀐다. 바꾼 뒤 상태 줄에 '되돌리기'가 보이고 누르면 이전 역본으로 돌아간다.
  • 안 풀리는 경우(참조 불가·책 없음·절 부족) 문구가 위 표대로 나오고 칩·본문은 바뀌지 않는다.
  • Tab 으로 머리줄·손잡이·⋯·칩에 닿을 수 있고 포커스 외곽선이 보인다. 스크린리더 이름이 위 접근성 항목과 같다.
  • 7개 앱 테마에서 삽입 선·강조·비활성 글이 모두 구분되어 읽힌다(colorScheme 사용, 하드코딩 색 없음).

결정 필요 항목

  1. 그룹째 이동 입력 — 머리줄 손잡이 끌기 + ⋯ 위/아래 메뉴 둘 다 / 끌기만 · 추천: 둘 다 (끌기 못 하는 사용자·긴 목록 대안, 비용 작음). 참고: tech-frontend 는 v1 제외를 제안했으나 plan.md 가 포함이라 plan 기준으로 그림.
  2. 빈 그룹 저장 — 세션만(안내 문구 표시) / 저장 · 추천: 세션만 (plan 추천. 저장은 스키마 칸 추가, 되돌리기 어려움). 단 저장 때 "저장되지 않았습니다" 안내가 필수.
  3. 역본 칩 위치 — 현재 슬라이드 머리줄 / 툴바 줄 / 썸네일 메뉴 · 추천: 머리줄(성경일 때만, 현재 항목과 가까워 어느 항목이 바뀌는지 분명). 확인 필요.
  4. 손잡이 키보드 이동(Alt+↑/↓) 포함 여부 — v1 포함 / 후속 · 추천: 후속(끌기 + 절 Enter 담기 + 그룹 ⋯ 이동으로 v1 최소 접근성 확보). 필요하면 올림.
  5. 그룹 만들기 시 고른 항목 처리 — 고른 항목을 넣기 / 항상 빈 그룹 · 추천: 고른 게 있으면 넣기(칩 일일이 누르는 불편 해소). 편집 탭 목록은 현재 다중 선택이 없어 '고른 항목' = 현재 고른 한 개로 제한(확인 필요).
  6. '모든 성경 항목에도 적용' 체크 — 4-B 드롭다운에 포함 / 제외 · 추천: 포함(기본 꺼짐, plan 결정 1 과 같음).
  7. 옛 칩(ItemGroupChip) — 안정화 뒤 제거(plan) / 즉시 숨김 · 추천: plan 대로 안정화 뒤 제거. 그때까지 트리 안 행에서는 칩을 숨겨 시각 중복을 줄인다.
