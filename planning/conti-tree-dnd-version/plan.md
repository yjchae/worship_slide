# 기획서: 콘티 폴더(트리) 그룹 · 끌어 놓아 원하는 자리에 담기 · 발표 보기 성경 역본 바꾸기

(기획자 보고를 팀장이 저장. 줄 번호는 조사 시점 값이라 구현 때 다시 확인.)

## 목적

| # | 요구 | 한 줄 목표 |
|---|---|---|
| 1 | 그룹을 폴더(트리)로 | 칩을 일일이 누르지 않고, 그룹을 만든 뒤 곡·말씀·PPT·빈 페이지를 그 안으로 옮기면 포함 |
| 2 | 원하는 자리에 담기 | 찬양·성경 검색 결과를 끌어 콘티 목록의 원하는 자리(그룹 안 포함)에 놓기. 지금은 맨 끝만 |
| 3 | 담은 뒤 역본 바꾸기 | 담은 성경 항목을 발표 보기에서 다른 역본으로 바꿔 표시 |

독립 배포 순서: **A(역본, 요구 3) → B(자리 지정, 요구 2) → C(트리, 요구 1)**

## 지금 구조

- 콘티 = 납작한 `_stagingItems` + 항목 uid→이름 `_itemGroups`. DB `worship_conti_items.item_group` 한 칸(스키마 20). 지금 그룹 = 같은 이름이 이어진 구간일 뿐, 빈 그룹 없음.
- 그룹 지정은 `ItemGroupChip`(conti_group_widgets.dart)·`_assignGroupRange`. 옮기기·나누기·삭제·붙여 넣기 경로가 `_itemGroups` 를 같이 옮김(`_onStagingReorder`, `_rebuildItem`, `_removeStagingWhere`, `_insertItemsAfterSlide`, `_replaceConti`, `_appendConti`).
- 콘티 목록 `_StagingPanel` = `ReorderableListView.builder`(중첩·행 사이 끼워 놓기 불가). 패널 전체가 `DragTarget<PraiseSong>` 하나 → `_addSongToStaging` 맨 끝. 곡 검색 행만 `Draggable`.
- 성경: 검색 탭 '담기' → `_addSelectedVerses` → `_bibleItemsFor` → `_addBibleItem`(맨 끝). 절 행은 끌 수 없음.
- 성경 항목 = `BibleStagingItem(reference, text, subText, extraText)`. `reference` = `역본 책 장:절`(`parseBibleReference` 로 풀림). 전역 보조·추가 역본 변경은 `_reapplyBibleVersions` 가 처리. 주 역본을 항목에서 바꾸는 길은 없음.
- 참고 패턴: 발표 보기 `_ThumbDragDrop`(앞/뒤 절반), `_EdgeAutoScroll`, `test/thumb_click_test.dart`.

## 범위

한다
- A: 성경 항목 하나의 주 역본 바꾸기(발표 보기). 결과가 콘티 저장·PPTX 에 그대로 따라감.
- B: 곡·성경 절을 끌어 행 사이(앞/뒤)에 놓기. 그룹 안에 놓으면 그 그룹에 듦.
- C: 그룹 폴더 트리(접기/펼치기, 만들기·이름 바꾸기·풀기·삭제, 항목 끌어 넣고 빼기, 그룹째 이동).

안 한다
- 중첩 그룹(1단계만), 빈 그룹 저장, 역본 변경을 임시 표시 상태로 두기, 발표 보기 격자 접기, 스키마 올리기(20 유지), 렌더러·네이티브 변경, 손으로 고친 본문 보존(역본 변경 시 새 본문으로 다시 만듦 — 확인창).

## 변경 설계

### A. 발표 보기에서 성경 역본 바꾸기
- 현재 슬라이드가 성경 페이지일 때만 역본 선택 칩. 바꾸면 그 항목의 reference 앞 역본·text·보조·추가가 새 역본 기준으로 재생성. uid·배경·메모·그룹 유지. 발표 중이면 `_sendCurrentSlide`. 직전 1회 되돌리기.
- `_changeBibleVersion(uid, newVersion)` 은 `_reapplyBibleVersions` 를 본뜸: reference 풀기 → `mapBookName` → 장 읽기 → text `'${v}. 본문'` → 보조·추가는 전역 역본 기준(새 역본과 같으면 비움). 읽는 사이 항목이 고쳐졌으면 고친 쪽 유지. 못 찾으면 바꾸지 않고 안내.
- 66권 아닌 역본은 비활성. 스냅샷이라 저장·`.wsconti`·PPTX 변경 없음.
- UI 정확한 자리는 확인 필요(현재 슬라이드 머리줄 칩 vs 썸네일 메뉴).

### B. 끌어 놓아 원하는 자리에 담기
- 새 `conti_insert_target.dart`: 행을 감싸 `DragTarget<PraiseSong>`/`<BibleDrag>` 로 앞/뒤 구분, 콜백 = (기준 uid, 앞/뒤). C 에서 재사용.
- `_insertSongAt`·`_insertItemsAt`(기준 uid 로 자리를 다시 찾음 — 성경은 await 뒤 항목이 바뀔 수 있음, 없으면 맨 끝). 여백 규칙은 `_onStagingReorder` 를 본뜸. 놓은 자리 이웃의 그룹 상속. 놓은 뒤 `_flashInserted` 강조.
- 성경 절 `Draggable`(체크 절이 있고 그중 하나를 끌면 고른 전부). 더블클릭·담기 버튼·패널 빈 곳 놓기는 맨 끝 유지.
- 중첩 `DragTarget` 우선순위는 미확인 → 위젯 테스트로 확인.

### C. 콘티 폴더(트리) 그룹
- 모델: 목록은 납작하게 두고 화면만 트리. 불변식 = 한 그룹의 항목은 목록에서 이어짐(끌어 넣기·빼기·그룹 이동 시 실제 재배치). DB·`.wsconti` 는 `item_group` 그대로(옛 호환 공짜). 옛 콘티에서 같은 이름이 떨어져 있으면 별개 두 그룹. 그룹 식별 = (이름, 구간 시작 uid). 접힘·빈 그룹은 세션만.
- 흐름: '그룹 만들기' → 이름 → 고른 항목이 들어가거나 빈 그룹. 머리줄 ▸/▾·이름 더블클릭 바꾸기·항목 수·⋯ 메뉴(이름/풀기/그룹과 항목 삭제/위·아래). 항목을 머리줄·그룹 행에 놓으면 소속, 밖 행에 놓으면 이탈. 머리줄 끌면 그룹째 이동. 접힌 그룹에 놓으면 맨 끝에 들고 강조.
- 새 `domain/conti_tree.dart`(순수 함수: 행 목록 계산·이동 연산·테스트). `_StagingPanel` 의 `ReorderableListView` 를 자체 목록 + `Draggable<_ContiDrag>` + `ContiInsertTarget` 으로 교체. `_moveStagingItems` 가 순수 연산 결과 적용. 칩·번호 범위는 트리 안정화 뒤 제거. repository·발표 보기 격자는 그대로.

## 수용 기준

A
- [ ] 성경 페이지에서만 역본 선택 보임(찬양·PPT·빈 페이지는 안 보임)
- [ ] 바꾸면 그 항목만 제목 역본·본문 변경, uid·그룹·배경·메모·위치 유지
- [ ] 새 역본 = 보조/추가 역본이면 그 칸 비움
- [ ] 발표 중 관객 화면 즉시 반영
- [ ] 절·책 없으면 변경 없이 안내
- [ ] 저장→불러오기, PPTX 에 새 역본 반영
- [ ] 되돌리기 1회 동작
- [ ] 손으로 고친 본문이 있으면 확인창
- [ ] 기존 `_reapplyBibleVersions` 동작 그대로

B
- [ ] 곡을 행 앞/뒤에 놓으면 그 자리 삽입, 놓을 자리 선 표시
- [ ] 성경 절(하나/고른 여러 절)이 페이지 수만큼 항목으로 순서대로 삽입
- [ ] 빈 곳 놓기·더블클릭·담기 버튼은 맨 끝(기존)
- [ ] 그룹 안 행에 놓으면 그 그룹에 듦
- [ ] await 사이 항목을 지워도 안 죽고 남은 기준/맨 끝에 삽입
- [ ] 발표 중 보던 슬라이드 유지
- [ ] 행 순서 바꾸기·썸네일 끌기·더블클릭과 서로 안 막음

C
- [ ] 그룹 만들기·이름 바꾸기·풀기(항목 유지)·그룹과 항목 삭제(재확인)
- [ ] 곡·성경·PPT·빈·편집 페이지 항목 모두 넣고 뺄 수 있음
- [ ] 끌어 넣기/빼기, 그룹째 이동(순서 유지, 다른 그룹과 안 섞임)
- [ ] 접어도 슬라이드 순서·페이지 수·자동 여백 동일
- [ ] 저장→불러오기 동일, 빈 그룹은 저장 안 됨(안내)
- [ ] 옛 콘티 동일 구성으로 열림, 떨어진 같은 이름은 두 그룹
- [ ] 발표 보기 격자 구간 머리줄이 트리 그룹과 일치
- [ ] 뒤에 붙이기에서 붙은 그룹 유지
- [ ] `conti_tree_test.dart` + 기존 `conti_group_test`·`slide_group_test` 통과
