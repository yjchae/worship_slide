# 찬양·콘티 동기화 접속 키 발급 방법 (관리자용)

여러 PC 가 구글 드라이브로 찬양·콘티를 주고받으려면 **접속 키**(`WS1-…` 로 시작하는 한 줄)가 필요하다.
관리자가 아래 과정을 **한 번만** 하고, 만든 키를 쓸 사람들에게만 따로 건넨다.
사용자는 앱에 키를 붙여 넣기만 하면 된다(구글 로그인·드라이브 앱 필요 없음).

> 키는 git·배포 zip 에 넣지 않는다. 레포가 공개라서 올리면 누구나 동기화 폴더를 읽고 지울 수 있다.

---

## 1. 프로젝트 만들기

1. <https://console.cloud.google.com> 에 **동기화 파일을 맡을 구글 계정**으로 로그인
2. 맨 위 프로젝트 선택 → **새 프로젝트** → 이름(예: `worship-slides-sync`) → **만들기**
3. 만든 프로젝트가 위쪽에 선택돼 있는지 확인

## 2. Google Drive API 켜기

1. 왼쪽 메뉴 **API 및 서비스 → 라이브러리**
2. `Google Drive API` 검색 → **사용**

## 3. OAuth 동의 화면 (Google 인증 플랫폼)

왼쪽 메뉴 **API 및 서비스 → OAuth 동의 화면** (콘솔에 따라 **Google 인증 플랫폼**으로 이동)

1. **시작하기**
   - 앱 이름: `Worship Slides`
   - 사용자 지원 이메일: 본인 메일
   - 대상: **외부**
   - 연락처 이메일: 본인 메일
   - 정책 동의 → **만들기**
2. **데이터 액세스** 탭은 건너뛴다 (스크립트가 `drive.file` 권한만 요청한다)
3. **대상(Audience)** 탭 → **앱 게시 → 프로덕션으로 푸시**

> ⚠️ 이 단계를 꼭 해야 한다. **테스트 상태로 두면 키가 7일 뒤 만료된다.**
> `drive.file` 권한만 쓰므로 구글 검증 심사는 필요 없다.

## 4. OAuth 클라이언트 만들기

1. **클라이언트** 탭 (또는 **API 및 서비스 → 사용자 인증 정보 → 사용자 인증 정보 만들기 → OAuth 클라이언트 ID**)
2. 애플리케이션 유형 **데스크톱 앱**, 이름은 아무거나 → **만들기**
3. 뜨는 창에서 **JSON 다운로드** → `client_secret_….json` 파일

## 5. 키 만들기

```bash
cd <worship_slides 폴더>
python3 scripts/make_sync_key.py ~/Downloads/client_secret_*.json
# 폴더 이름을 바꾸려면: python3 scripts/make_sync_key.py <json 파일> "찬양 동기화"
```

1. 브라우저가 열리면 **1번과 같은 계정**으로 로그인
2. **"Google에서 확인하지 않은 앱"** 경고가 나오면 → **고급 → Worship Slides(으)로 이동** → **계속**
   (직접 만든 앱이라 나오는 경고다)
3. "로그인 완료" 화면이 나오면 창을 닫고 터미널로 돌아온다
4. 터미널에 이렇게 나온다

   ```
   드라이브에 'worship_slides_sync' 폴더를 만들었습니다. 아래 접속 키를 쓸 사람들에게만 건네세요:

   WS1-eyJjbGllbnRfaWQiOi...
   ```

   `WS1-` 로 시작하는 **한 줄 전체**가 접속 키다.

## 6. 앱에 넣기 (각 PC)

1. 앱 **가져오기 메뉴 → 찬양·콘티 동기화**
2. 키를 붙여 넣고 **연결**
3. 다른 PC 에도 **같은 키**를 넣는다 (카카오톡·메일 등으로 쓸 사람에게만 따로 전달)

---

## 알아 둘 것

- **모든 PC 가 관리자 계정으로 접속한다.** 그래도 권한이 `drive.file` 이라 이 앱이 만든 파일(동기화 폴더)만 보이고,
  드라이브의 다른 파일은 보이지 않는다. 파일은 관리자 드라이브 용량을 쓴다.
- 드라이브에서 **손으로 만든 폴더는 앱이 못 본다**(`drive.file` 권한). 폴더는 반드시 스크립트가 만든다.
- 스크립트를 **다시 실행하면 새 폴더·새 키**가 생긴다. 모든 PC 가 같은 키를 써야 서로 맞춰진다.
- `client_secret_….json` 은 git 에 안 올라가게 막아 두었다(`.gitignore`). 키를 다시 만들 때만 필요하니 따로 보관한다.
- **키를 끊으려면** <https://myaccount.google.com/permissions> 에서 `Worship Slides` 접근 삭제.
  모든 PC 가 막히므로 새 키를 만들어 다시 건넨다.
- 앱에서 키를 지우려면 동기화 창의 **연결 끊기** (드라이브 파일은 그대로 남는다).

## 문제가 생기면

| 증상 | 원인 / 해결 |
|---|---|
| 앱에 "접속 키 모양이 아닙니다" / "잘렸거나 잘못 복사" | 키 한 줄을 끝까지 다 복사했는지 확인 (`WS1-` 부터) |
| 앱에 "접속 키를 더 이상 쓸 수 없습니다" | 동의 화면이 테스트 상태(7일 만료)였거나 권한을 끊었다 → 3번 확인 후 5번부터 다시 |
| 앱에 "동기화 폴더나 파일을 찾지 못했습니다" | 드라이브에서 폴더를 지웠다 → 휴지통에서 복원하거나 5번부터 다시 |
| 스크립트가 "refresh token 을 받지 못했습니다" | 클라이언트 유형이 데스크톱 앱인지 확인 |
| 로그인 화면에 "액세스 차단됨" | 동의 화면 대상이 테스트이고 테스트 사용자에 본인이 없다 → 3번 '프로덕션으로 푸시' |
