1. 프로그램 소개

예배 슬라이드는 교회 예배 준비에 특화된 데스크탑 도구입니다. 흩어져 있는 찬양 PPT를 한 곳에 모아 검색하고, 성경 본문·외부 PPT/PDF·빈 페이지까지 하나의 예배 콘티로 조립한 뒤, 보조 모니터로 직접 발표하거나 PPTX 파일로 내보낼 수 있습니다.

찬양 폴더 일괄 가져오기.ppt / .pptx 파일을 폴더째 불러와 가사를 자동으로 데이터베이스에 저장
한 · 영 가사 자동 분리한 슬라이드에 한글과 영어가 섞여 있어도 자동으로 구분해서 저장
제목 · 가사 검색곡 제목 또는 가사 내용으로 즉시 검색, 검색 범위 선택 가능
성경 본문성경 JSON을 불러와 버전 · 책 · 장 · 절 단위로 선택해 슬라이드로 추가
외부 PPT · PDF기존 PPT/PDF 파일을 페이지 이미지로 변환해 콘티에 그대로 삽입
예배 콘티 저장완성한 순서를 이름 붙여 저장하고 다음 주에 다시 불러오기
발표 모드보조 모니터에 전체화면 송출, 키보드 단축키로 이동 · 화면 끄기
발표 보기메인 화면에는 다음 슬라이드 · 경과 시간 · 발표 메모 · 관객 화면 포인터
PPTX 내보내기배경 · 글자색 · 크기 · 정렬 · 폰트 · 배경 이미지를 설정해 PPTX 생성

시스템 요구사항

  • macOS 또는 Windows 데스크탑
  • LibreOffice (선택) — .ppt(구형) 가져오기와 PPT 이미지 변환에 필요합니다. .pptx와 .pdf는 LibreOffice 없이 동작합니다.
  • 발표용 보조 모니터 (선택) — 없으면 창 모드로 발표합니다.

2. 처음 시작하기 · 화면 구성

2.1 실행

설치 폴더에서 Worship Slides.app(macOS) 또는 worship_slides.exe(Windows)를 실행합니다. 첫 실행 시 데이터베이스가 자동으로 만들어집니다.

📌 참고 — 데이터베이스 파일(worship_slides.db)은 앱 폴더 안에 저장됩니다. 앱 폴더를 통째로 옮기거나 복사하면 저장한 곡과 콘티도 함께 따라갑니다.
⚠ 주의 (macOS) — 서명되지 않은 앱이라 처음 실행할 때 경고가 뜰 수 있습니다. 배포본에 함께 들어 있는 Unlock Worship Slides.command를 한 번 실행한 뒤 앱을 열어 주세요.

2.2 화면 구성

상단 헤더 바PPT · PDF 가져오기 / 찬양폴더 선택 / 성경 불러오기 / 저장된 로그 추출 / 업데이트 확인
왼쪽 위 — 예배 콘티발표할 항목의 순서 목록. 저장 · 불러오기 · 빈 페이지 추가 · 순서 변경
왼쪽 아래 — 검색 패널찬양 검색 탭과 성경 검색 탭
오른쪽 — 편집 탭슬라이드 미리보기와 PPTX 디자인 설정, PPTX 저장 버튼
오른쪽 — 발표 보기 탭발표자 콘솔: 현재 · 다음 슬라이드, 경과 시간, 발표 메모, 포인터
💡 팁 — 패널 사이의 구분선을 드래그하면 크기를 조절할 수 있고, 각 패널의 접기 아이콘으로 화면을 넓게 쓸 수 있습니다.

3. 찬양 가져오기 (PPT/PPTX 폴더)

찬양 PPT 파일이 모여 있는 폴더를 한 번 가져오면, 가사가 데이터베이스에 저장되어 이후에는 검색만으로 곡을 꺼내 쓸 수 있습니다.

  1. 상단 헤더의 [찬양폴더 선택]을 클릭합니다.
  2. PPT/PPTX 파일이 있는 폴더를 선택합니다. 하위 폴더까지 자동으로 탐색합니다.
  3. 읽는 중 표시와 함께 파일을 분석합니다. 파일 수에 따라 수 초 ~ 수 분 걸립니다.
  4. 완료되면 "N개 추가, 중복 M개 건너뜀" 알림으로 결과를 확인합니다.
💡 팁 — 같은 폴더를 여러 번 가져와도 안전합니다. 이미 저장된 곡은 건너뛰고 새 곡만 추가됩니다.
⚠ 주의 — .ppt(구형) 파일이 섞여 있는데 LibreOffice가 없으면 "LibreOffice가 필요합니다" 안내가 뜹니다. .pptx만 있다면 이 안내는 나타나지 않습니다.

3.1 가사 페이지 나누는 규칙

가사는 빈 줄을 기준으로 페이지가 나뉩니다. 가사를 직접 입력하거나 수정할 때도 같은 규칙입니다.

  • 빈 줄 하나 = 페이지 구분
  • 가사 맨 앞의 빈 줄 = 빈 페이지(간주 등)로 보존
  • 한 줄의 라틴 문자 비율이 60% 이상이면 영어 가사로 분류됩니다.

3.2 곡 직접 추가 · 수정 · 삭제

새 곡 추가찬양 검색 패널의 [새 곡] 버튼 → 제목 · 한글 가사 · 영어 가사(선택) 입력 후 저장
가사 수정곡 목록에서 수정 아이콘을 눌러 제목과 가사를 편집
선택 곡 삭제곡을 체크한 뒤 [선택 곡 삭제]
DB 초기화저장된 찬양을 모두 삭제합니다. 되돌릴 수 없으니 주의하세요.

4. 성경 불러오기

성경 본문을 쓰려면 성경 JSON 파일을 한 번 불러와야 합니다. 한 번 저장하면 계속 유지됩니다.

  1. 상단 헤더의 [성경 불러오기]를 클릭합니다.
  2. 성경 JSON 파일을 선택합니다.
  3. 버전 이름을 입력합니다. (예: 개역개정, 새번역, KRV)
  4. "OO 성경 N절을 저장했습니다" 알림이 뜨면 완료입니다.
📌 참고 — 지원하는 JSON 형식
• [{"book":"창세기","chapter":1,"verse":1,"text":"…"}]
• 책 이름을 키로 갖는 중첩 객체 형식
• 장 · 절이 배열로 중첩된 형식
여러 버전을 각각 다른 이름으로 저장해 두고 골라 쓸 수 있습니다.

5. 예배 콘티 만들기

왼쪽 위 예배 콘티 패널이 실제로 발표하거나 내보낼 순서입니다. 네 가지 항목을 담을 수 있습니다.

5.1 찬양 추가

  1. 찬양 검색 탭 검색창에 제목이나 가사 키워드를 입력합니다.
  2. 검색 범위(제목 / 가사)를 체크박스로 조절할 수 있습니다.
  3. 목록에서 곡을 클릭해 체크하면 곧바로 콘티에 추가됩니다. 다시 클릭하면 빠집니다.

5.2 성경 본문 추가

  1. 성경 검색 탭에서 버전 · 책을 고르고 장 번호를 입력합니다.
  2. 절 목록에서 필요한 절을 체크합니다. 여러 절을 한 번에 고를 수 있습니다.
  3. 페이지당 절 수(1 · 2 · 3 · 4 · 5 · 10)를 고릅니다.
  4. [N절 M페이지로 추가] 버튼을 누르면 콘티에 들어갑니다.

5.3 외부 PPT · PDF 추가

이미 만들어 둔 광고 PPT나 악보 PDF를 그대로 콘티에 넣을 수 있습니다.

  1. 상단 헤더의 [PPT · PDF 가져오기]를 클릭합니다.
  2. 파일을 선택하면 전 페이지가 이미지로 변환되어 콘티에 순서대로 추가됩니다.
⚠ 주의 — PPT/PPTX 변환에는 LibreOffice가 필요합니다. PDF는 LibreOffice 없이 변환됩니다. 가져온 PPT 슬라이드는 이미지이므로 내용을 수정할 수 없습니다.

5.4 빈 페이지 추가

콘티 패널의 [빈 페이지 추가]로 배경만 있는 빈 슬라이드를 넣을 수 있습니다. 기도 시간이나 화면 정리용으로 쓰세요.

5.5 순서 관리

순서 변경항목의 ⠿ 핸들을 드래그해 위아래로 이동
항목 제거항목 오른쪽 ✕ 버튼. 찬양이면 검색 목록의 체크도 함께 해제됩니다.
미리보기 전환항목을 클릭하면 오른쪽 편집 탭의 미리보기가 해당 항목으로 이동
슬라이드 수정곡 항목의 수정 버튼으로 그 자리에서 가사를 다듬을 수 있습니다.
전체 초기화콘티를 비웁니다.

6. 콘티 저장 · 불러오기

6.1 저장

  1. 콘티 패널의 [콘티 저장]을 클릭합니다.
  2. 이름을 입력합니다. (기본값으로 날짜 기반 이름이 채워집니다)
  3. [저장]을 누르면 "OO 콘티를 저장했습니다" 알림이 뜹니다.
📌 참고 — 콘티에는 곡 번호뿐 아니라 그때의 가사 내용까지 함께 저장됩니다. 나중에 곡을 지우거나 폴더를 다시 가져와도 저장한 콘티는 깨지지 않습니다.

6.2 불러오기

  1. [콘티 불러오기]를 클릭하면 저장된 목록(이름 · 날짜 · 항목 수)이 나옵니다.
  2. 불러올 콘티를 고릅니다. 현재 작업 중인 항목이 있으면 교체할지 확인합니다.
  3. 목록에서 [콘티 삭제]로 필요 없는 콘티를 지울 수 있습니다.

7. 디자인 설정 (편집 탭)

오른쪽 편집 탭에서 슬라이드 모양을 정합니다. 변경 사항은 미리보기에 바로 반영되고, 발표 화면과 내보낸 PPTX가 미리보기와 똑같이 보입니다. 설정은 찬양과 성경본문 각각 따로 지정합니다.

글자 크기가사 · 본문의 글자 크기(pt)
본문 수평 정렬좌측 / 중앙 / 우측
본문 수직 위치상단 / 중단 / 하단
본문 상단 여백텍스트 상자를 위아래로 미세 조정
배경 색상스와치에서 고르거나 #RRGGBB 직접 입력
배경 이미지이미지 파일을 배경으로 지정 (없음으로 되돌릴 수 있음)
한글 가사 색상한국어 가사 글자색
영어 가사켜면 영어 가사도 함께 표시. 색상은 따로 지정
제목 표시곡 제목 / 성경 참조(예: 롬 8:28)를 슬라이드에 표시
제목 크기 · 색상 · 위치제목의 크기, 색, 수평 · 수직 위치

💡 팁 — 설정은 자동으로 저장되어 앱을 다시 켜도 그대로 유지됩니다. [리셋]으로 기본값으로 되돌릴 수 있습니다.

8. PPTX 내보내기

콘티에 담긴 항목 전체를 하나의 PPTX 파일로 만듭니다. PowerPoint · Keynote · LibreOffice Impress에서 바로 열립니다.

  1. 콘티에 항목이 모두 들어 있는지 확인합니다.
  2. 편집 탭에서 미리보기를 보며 디자인을 조정합니다.
  3. [선택한 항목으로 PPTX 저장]을 클릭합니다.
  4. 저장 위치와 파일 이름을 정하면 "PPTX 저장 완료" 알림이 뜹니다.
📌 참고 — 내보낸 PPTX를 다른 컴퓨터의 PowerPoint에서 열 때 글꼴이 다르게 보일 수 있습니다. 앱은 사용한 폰트를 사용자 폰트 폴더에 자동으로 설치해 두지만, 파일을 옮겨서 열 컴퓨터에는 같은 폰트가 없을 수 있습니다.

9. 발표 모드

PPTX로 내보내지 않고 앱에서 바로 화면에 띄울 수 있습니다.

  1. 콘티를 완성합니다.
  2. [발표 시작]을 클릭합니다.
  3. 보조 모니터가 있으면 그 화면에 전체화면으로, 없으면 별도 창으로 슬라이드가 뜹니다.
  4. 키보드나 발표 보기 탭의 버튼으로 슬라이드를 넘깁니다.
  5. [발표 종료] 또는 ESC로 끝냅니다.

9.1 단축키

→ ↓ Space다음 슬라이드
← ↑이전 슬라이드
숫자 + Enter해당 번호의 슬라이드로 바로 이동
B화면 끄기 (검은 화면) / 다시 켜기
ESC발표 종료
💡 팁 — 단축키는 메인 창이 선택된 상태에서 동작합니다. 발표 화면을 클릭했다면 메인 창을 한 번 클릭한 뒤 사용하세요.

10. 발표 보기 (발표자 콘솔)

오른쪽 발표 보기 탭은 발표자만 보는 화면입니다. 관객 화면에는 나오지 않습니다.

현재 슬라이드관객이 보고 있는 화면을 그대로 표시
다음 슬라이드바로 다음에 나올 화면을 미리 확인
경과 시간발표 시작부터의 시간. 일시정지 · 리셋 가능
발표 메모슬라이드마다 할 말을 적어 둘 수 있고, 콘티를 저장하면 메모도 함께 저장됩니다.
관객 화면 포인터손가락 / 레이저 / 숨김. 미리보기 위에서 마우스를 움직이면 관객 화면에 그대로 표시됩니다. 크기도 조절할 수 있습니다.
모든 페이지 보기전체 슬라이드를 격자로 보고 원하는 페이지로 바로 이동
영역 확대슬라이드의 일부를 크게 확대해 보여 주기
화면 끄기관객 화면만 검게 만들기 (B와 동일)
📌 참고 — 자동으로 들어간 여백 페이지에는 메모를 저장할 수 없습니다. [빈 페이지 추가]로 만든 페이지에는 저장됩니다.

11. 업데이트 · 로그

11.1 업데이트

앱을 켜면 새 버전이 있는지 자동으로 확인하고 안내 배너를 띄웁니다. 상단 헤더의 [업데이트 확인]으로 직접 확인할 수도 있습니다. [지금 업데이트]를 누르면 새 버전을 내려받습니다.

11.2 로그

문제가 생겼을 때 상단 헤더의 [저장된 로그 추출]로 기록을 확인하거나 [로그 폴더 열기]로 로그 파일을 열어 개발자에게 전달할 수 있습니다.
