# Worship Slides 개인정보처리방침

Worship Slides(이하 "앱")는 개인정보를 개발자 서버로 보내거나 모으지 않습니다.

## 앱이 다루는 정보

- 찬양 가사·성경·콘티 등 앱 데이터는 **사용자 PC 안**(앱 폴더의 DB 파일)에만 저장됩니다.
- **찬양·콘티 동기화**를 켜면, 관리자가 만든 접속 키로 Google Drive 에 접속해 찬양·콘티 파일을 읽고 씁니다.
  - 요청하는 권한은 `drive.file` 하나뿐입니다. 앱이 직접 만든 파일(동기화 폴더)만 보이며, 드라이브의 다른 파일은 읽을 수 없습니다.
  - 접속 키는 각 PC 의 앱 설정 폴더(`sync_key.txt`)에만 저장되고, 개발자를 포함한 제3자에게 전송되지 않습니다.
  - Google 사용자 데이터는 동기화 기능을 위해서만 쓰며, 판매·광고·분석에 쓰거나 다른 곳에 넘기지 않습니다.

## 접근 끊기·삭제

- <https://myaccount.google.com/permissions> 에서 `Worship Slides` 접근을 삭제하면 앱은 더 이상 드라이브에 접속하지 못합니다.
- 앱 동기화 창의 **연결 끊기**로 PC 에 저장된 접속 키를 지울 수 있습니다. 드라이브의 동기화 폴더는 Google Drive 에서 직접 지우면 됩니다.
